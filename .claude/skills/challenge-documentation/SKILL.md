# Challenge Documentation

Help prepare the `LOG.md` submission for the Monks technical challenge.

## Sources

- `LOG.md.example`
- `gtm-container.json`
- `website/`
- Apps Script source files, when available
- Test results explicitly confirmed by the candidate

## Instructions

1. Follow the structure of `LOG.md.example`.
2. Write professional, clear English suitable for technical stakeholders.
3. Explain technical decisions concisely.
4. Use repository evidence to support implementation claims.
5. Never claim that GTM Preview, GA4 DebugView, or Google Sheets tests passed unless the candidate confirms them.
6. Never invent Google Sheet URLs, test results or completed features.
7. Mark incomplete sections as pending.
8. Keep emails understandable to their intended recipients.
9. Identify missing information before finalizing the submission.

## Output

- A proposed `LOG.md` draft
- Missing information
- Potential inconsistencies
- Recommendations before submission

Do not modify files unless explicitly requested.
